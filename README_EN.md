# 📌 Manual Testing QA Project

*Read in [Portuguese (PT-BR)](./README.md)*

Portfolio created to demonstrate practical skills in manual testing, QA strategy, and technical documentation. It includes Test Plans, Test Cases, Bug Reports, and Test Summary metrics.

## 🎯 Objective

To showcase essential QA competencies:

*   Creation of detailed Test Cases
*   Functional Testing
*   Exploratory Testing
*   API Testing (Optional)
*   Professional Bug Reporting
*   Regression and Smoke testing
*   Organization, clarity, and business risk analysis

## 🛠 Tools Used

*   Markdown (Documentation)
*   Google Sheets / Excel
*   Browser (Chrome DevTools for debugging)
*   Test Environment: saucedemo.com
*   Screen capture for evidence

## 📂 Project Structure

*   `/test-plan` → Test Strategy and Planning
*   `/test-cases` → Detailed Test Cases (Happy paths & Negative testing)
*   `/test-scenarios` → High-level Test Scenarios
*   `/bug-reports` → Detailed Bug Reports (Steps to reproduce, Expected vs Actual, Evidence)
*   `/evidences` → Execution screenshots and logs
*   `/checklists` → Regression and Smoke test checklists
*   `test-summary-report.md` → Final QA metrics and Go/No-Go recommendation

## 📈 Results & Impact

This project demonstrates the ability to:

*   Document tests clearly in technical English
*   Identify critical system failures before production deployment
*   Create comprehensive testing scenarios mimicking real user behavior
*   Organize test evidence efficiently
*   Work within a real-world QA workflow (Agile context)
